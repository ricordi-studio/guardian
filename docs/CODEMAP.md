## 配布境界(何を配り、何を配らないか。2026-08-29)

★正本のリポジトリには【配るもの】と【Guardian 自身がこの現場で使うもの】が同居している。
  この区別はどこにも宣言されていなかったので、後追いの列挙で3回漏れた。

- 宣言(**白と黒の両方**・ここだけが正本): `pull.mjs` の `配るもの` と `現場のもの`。
  **どちらにも無いものが1つでもあれば `pull.mjs` は取らずに止まる**(門)
- 配るものの正本: `selfcheck.mjs` の `ENGINE_FILES`(指紋照合と配布境界の照合が**同じ1つを読む**)
- 照合(3方向とも `selfcheck.mjs` ── 門と同じ宣言を読む双子。RULES 44条):
  - 直下が全部どちらか一方に分類されているか(**未分類は赤**)
  - エンジンが `配るもの` に入っているか(**欠落**の向き ── 配り忘れは黙って起きる)
  - `install.mjs` が配布先に作るものが全部 `現場のもの` に入っているか(**混入**の向き)
    ── **独立した第二根拠**。据え付ける道具は、配る道具と同じ境界を逆側から知っている
- ⚠罠の実績: 2026-08-29、`.claude` と `CLAUDE.md` が `現場のもの` に無く、配布先へ流れた

- ★白と黒を両方持つのは、**どちらか一方だと必ず逆向きの事故を引き受ける**から
  (ブラックだけ=混入 / ホワイトだけ=欠落。`research/council/findings/FIND-001.md` の Case G)。
