## 物差し(閾値・文字クラス・拡張子の判定。2026-08-30)

★**数字と文字クラスは、書いた人の現場の写真である。** `>= 2` `>= 4` `[A-Za-z0-9_.]{3,}` `#` は
どれも「英語で、空白の無い経路で、自分の手元で」正しかった。3つとも実測で外れた。

- 記号として数える長さ: `neighbors.mjs` の `日本語を含む` / `語として十分`(定義の採否)

- `#` の扱い: `井桁がコメントの言語`(sh/py/rb/yml…のときだけ落とす)。
  **知らない拡張子では落とさない** ── 落とせば見えない失敗、落とさなければ門が鳴るだけ
- ノートの欄名: `欄名`(全件・日本語可)+ `一般語`(既定はエンジン、`neighbors.common_keys` で差し替え可)
- ⚠**空白入りの経路**: git は差分の見出しの末尾に**タブ**を足す(`+++ b/a b.js<TAB>`)。
  `parseDiff` で落とす。落とさないと**そのファイルは門から丸ごと消える**
  ── この塊が空白入りの経路で壊れたのは**3度目**(install.mjs 冒頭 / --escaped / ここ)
- ⚠**この現場では出ない条件**が多い(経路に空白が無い・HTML を持たない)。**実測しないと一生出ない**

## 記号として何を拾うか(門が何を見られるか。2026-08-30)

★**拾えない書き方のファイルは、門から丸ごと消える。**しかも「器のコードに変更なし」で終わるので**無言**。

- 定義の判定: `neighbors.mjs` の `DEF_FN`(`function` / `async` / 生成器 / `export default`)

- 上位の記号だけ数える: 行頭の定義だけ(HTML の `<script>` 内は字下げを許す)。

  ── 近傍の軸(呼び出し関係)に乗らないので**問えない**が、**問えていないと言う**
- ⚠**見た目でコメント行を落とすのは、その報せだけ**。門の判定(`素にする`)には使わない
