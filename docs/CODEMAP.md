## 所有台帳 ── 入れたときを、外すときのために残す(2026-09-03)

★この項のファイル: `台帳.mjs` / `install.mjs`。

★★同じ `.guardian` が、`ROOT` から書けば現場の物、`HERE` から書けば塊の物になる。

```

.guardian/導入台帳.json … ★TARGET 側。★★guardian/ には置かない(2026-09-03 に移した)
