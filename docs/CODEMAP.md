## 配布境界(何を配り、何を配らないか。2026-08-29)

★正本のリポジトリには【配るもの】と【Guardian 自身がこの現場で使うもの】が同居している。
  この区別はどこにも宣言されていなかったので、後追いの列挙で3回漏れた。

- 配らないものの宣言: `pull.mjs` の `現場のもの`(**ここだけが正本**。増やすときは下の2つも見る)
- 配るものの正本: `selfcheck.mjs` の `ENGINE_FILES`(指紋照合と配布境界の照合が**同じ1つを読む**)
- 照合(2本とも `selfcheck.mjs`):
  - エンジンが `現場のもの` に紛れていないか(配るべきものが配られなくなる向き)
  - `install.mjs` が配布先に作るものが全部 `現場のもの` に入っているか(配ってはいけないものを配る向き)
    ── **独立した第二根拠**。据え付ける道具は、配る道具と同じ境界を逆側から知っている
- ⚠罠の実績: 2026-08-29、`.claude` と `CLAUDE.md` が `現場のもの` に無く、配布先へ流れた
  (配布先が `--check` で気づいて報告。取らずに止めた)
- ⚠**まだ閉じていない**: `install.mjs` が作らない現場固有物(`.guardian` / `research`)は
  上の照合では守れない。ホワイトリストへの反転は保留(反転すると**配り忘れが静かに起きる**
  ── `research/council/findings/FIND-001.md` の Case G)
